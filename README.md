# Ron Blog - fantasy

> 只是一个做梦记录的地方，可能没有什么技术含量，但是我还是想要进行展现出来，不为什么！就只是这是我仅剩会的~

在线访问：[https://cakee.eu.org/](https://cakee.eu.org/)

## 技术栈

- **框架**：[Hexo](https://hexo.io/)
- **主题**：[hexo-theme-redefine](https://github.com/EvanNotFound/hexo-theme-redefine)
- **部署**：GitHub Pages（推送至 `source` 分支触发 GitHub Actions 自动构建并部署到 `main` 分支）

## 本地预览

```bash
npm install
npx hexo clean && npx hexo server
```
